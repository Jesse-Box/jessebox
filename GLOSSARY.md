# jessebox

Jesse Box's personal site, documenting product design work.

## Language

**Case study**:
A documented product design project, told through text, images, media and interactive pieces.
_Avoid_: Project page, portfolio item

**Post**:
An entry from the original blog, retired in the rebuild and kept only in a private archive.
_Avoid_: Article, blog post

**Draft**:
A case study or page that exists but is not yet published.
_Avoid_: Unpublished, WIP

**Holding page**:
The single page that stands in for the whole site while it is being rebuilt.
_Avoid_: Under-construction page, one-pager, splash page
